description=Search and add Danish public base data from datagrundlag.dk as layers – latest snapshot or data as of a given date.
about=Unofficial browser for datagrundlag.dk, an open catalogue of Danish public base data (BBR, Matriklen, DAR, GeoDanmark, Plandata.dk, GeoFA, nature and environment data and more) published as GeoParquet and FlatGeobuf with a STAC catalogue. The plugin adds a panel where you can search all datasets, add the latest snapshot with a double-click, load data as it looked on a given date, and refresh all layers to the latest snapshot with one click. The user interface is in Danish. Tables without geometry are read as GeoParquet and require GDAL with the Parquet driver (e.g. OSGeo4W, QGIS 3.34+). Not affiliated with datagrundlag.dk or MapCentia.
